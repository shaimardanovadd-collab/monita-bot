# QonunRadar — тестовый Telegram-бот

## Что работает
- Telegram-интерфейс на aiogram 3 (long polling)
- /start, /menu, /help, /status, /search
- выбор сферы бизнеса и сохранение Telegram ID/выбранной сферы в SQLite
- просмотр и поиск по 225 исходным карточкам НПА и ссылкам Lex.uz
- меню «Изменения», «Проекты», «Календарь», «Настройки» с честной маркировкой неготовых интеграций

## Что НЕ работает (пока)
- автоматическая загрузка Lex.uz и Regulation.gov.uz
- подтверждение действующей редакции, отслеживание изменений, юридический матчинг и рассылки
- проверка дат, применимости, официальных редакций и полного текста
- расширенный профиль (регион, ОПФ, налоговый режим): схема допускает расширение, но UI ещё не сделан

## Запуск (Windows / macOS / Linux)
1. Создайте бота в Telegram через @BotFather командой /newbot, получите токен.
2. Установите Python 3.11+.
3. Распакуйте архив в папку.
4. В терминале в папке проекта выполните `python -m venv .venv`.
5. Активируйте окружение: Windows `.venv\\Scripts\\activate`, macOS/Linux `source .venv/bin/activate`.
6. Установите зависимости: `pip install -r requirements.txt`.
7. Скопируйте `.env.example` в `.env` и вставьте BOT_TOKEN. Никому не передавайте токен.
8. Запустите `python bot.py`.
9. Откройте своего бота в Telegram, нажмите Start.

Остановить: Ctrl+C. Пока программа запущена, бот отвечает; для 24/7 нужен сервер.
